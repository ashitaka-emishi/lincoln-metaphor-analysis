# Corpus Tier Definitions

V4 adds a stratified corpus architecture without replacing the validated v1 corpus. Each tier has a distinct evidentiary role, validation burden, and publication limit. The tiers must not be described as equivalent evidence.

## Tier 1 - 48-Document Core Interpretive Corpus

Tier 1 is the expanded fully annotated core corpus. It preserves all 28 v1 documents and adds 20 priority documents selected for period, register, rhetorical function, source quality, and relevance to the project's metaphor and absence questions.

Tier 1 is the only v4 tier designed to support full interpretive claims after annotation. Documents in this tier require:

- full document metadata;
- source provenance and source-integrity checks;
- normalized text and stable sentence IDs;
- full Stage 4-style annotation before they can contribute to interpretive counts;
- generated concordance, analysis, evidence-chain, reliability, coverage, and publication outputs.

The v1 document IDs, sentence IDs, source files, and Stage 4 annotations remain valid and preserved. V4 additions receive deterministic new IDs rather than renumbering existing documents.

## Tier 2 - 75-100 Document Extended Validation Corpus

Tier 2 is the broader validation corpus. It tests whether Tier 1 patterns are robust across a larger, more stratified sample of Lincoln writings. It is not a second fully annotated core unless a later issue explicitly promotes selected records to full annotation.

Tier 2 can support coverage, comparison, and light-validation claims after its metadata, provenance, text status, and light annotation fields are validated. It should be used to ask whether Tier 1 appears over-selected by period, genre, audience, or rhetorical function.

Tier 2 evidence must be reported separately from Tier 1. Light annotation is not equivalent to full Stage 4A annotation, and Tier 2 should not carry the same interpretive weight as the fully annotated core.

## Tier 3 - Search-Only Reference Corpus

Tier 3 is a search-only reference layer. It provides a larger discovery and context set for candidate passages, vocabulary checks, negative searches, and future selection work.

Tier 3 does not support corpus-level interpretive claims by itself. Search hits are leads, not coded evidence. A Tier 3 passage must move through documented selection, provenance, normalization, segmentation, and annotation gates before it can support interpretive findings.

## Cross-Tier Rules

- V4 does not claim to analyze all Lincoln writings.
- Larger corpus size reduces selection-bias risk but does not eliminate interpretive judgment.
- Tier labels must appear in generated inventories, coverage reports, reliability sampling notes, and publication-facing summaries.
- Tier 1, Tier 2, and Tier 3 outputs must be counted and cited separately unless a generated report explicitly defines a cross-tier denominator.
- Existing v1 artifacts remain canonical for the v1 publication corpus and for any reliability result tied to that corpus version.
